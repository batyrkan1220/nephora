Настройки лидерборда

Данные: воронка «Первичный», сделка считается после перехода в стадию «Заказ», день заказа берётся из поля «Дата заказа» (если пусто — дата перехода). Стадия «Предзаказ» не считается — сделка попадёт в лидерборд, только когда дойдёт до «Заказ».
Вебхук: Bitrix24 → Разработчикам → Другое → Входящий вебхук, права: crm, user, department. Вставьте URL вида https://nephora.bitrix24.kz/rest/1/xxxx/. Он хранится только в этом браузере.
Пустое поле = план по умолчанию. «Скрыть» убирает человека из лидерборда.
