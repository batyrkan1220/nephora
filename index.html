Настройки арены

Данные: сделки в стадиях «Заказ» и «Заказ на подтверждение» (Первичный) и «Заказ», «Заказ на подтверждение», «Курьерская доставка», «Доработка», «Доставлено/Оплачено» (Доставка). День заказа — поле «Дата заказа». «Предзаказ» и отказы не считаются.
Уровни (за месяц): Новичок → Бронза 300K → Серебро 700K → Золото 1.2M → Платина 2M → Легенда 3M.
Вебхук: Bitrix24 → Разработчикам → Другое → Входящий вебхук, права: crm, user, department. Хранится только в этом браузере.
Пустое поле = план по умолчанию. «Скрыть» убирает игрока с арены.
