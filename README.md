# Safa портал

Живой рейтинг менеджеров для телевизора в зале + кабинет руководителя. Продажи приходят из **Bitrix24** автоматически.

## Что есть

**Табло (ТВ)** — `/b/<ключ>`, без пароля
- Тройка лидеров с фото и коронами, таблица со всеми менеджерами
- Колонки: «Сегодня» (полоса к дневному плану), «Продажи» (полоса к личному плану), количество, % от продаж, зарплата
- План отдела на период и на сегодня, сколько осталось
- Попап новой продажи: фото, сумма, конфетти и звук
- Если менеджеров больше, чем помещается, — строка «Ещё N», последние три подсвечены красным
- Темы: Арена (яркая), Классика дневная, Классика ночная; горизонтальный и вертикальный экран; на телефоне — адаптивно

**Кабинет** — `/admin`, вход по паролю
- Главная: выручка, средний чек, сегодня, % от продаж, бонусы, к выплате, топ-менеджер, график по дням, таблица по менеджерам, CSV
- Лидерборды: несколько досок (отделы/филиалы), у каждой своя ссылка
  - Настройки: название, период (текущий месяц или даты), рейтинг по сумме/количеству, план отдела, личный план по умолчанию, ступени комиссии, бонусы за день/неделю/период
  - Экран: ссылка, ориентация, тема, колонки, попап/звук, тестовая продажа
  - Участники: отделы Bitrix24, ручное добавление, личные планы, исключения
- Менеджеры: своё фото, имя на табло, подпись (категория), скрыть со всех досок
- Продажи: список сделок за период, CSV
- Настройки: стадии «факт кассы», поле даты продажи, рабочие дни и праздники, интервал опроса Bitrix24

## Как считается
- **Продажа** = сделка в одной из отмеченных стадий; день продажи — по выбранному полю-дате (по умолчанию «Дата заказа»).
- **Дневной план** = план за период ÷ рабочие дни периода (в выходной — 0).
- **% от продаж** = процент от суммы каждой сделки по ступеням комиссии доски.
- **Бонус** = самая высокая достигнутая ступень за каждый день / неделю (пн–вс, внутри периода) / весь период; суммируется.
- **Зарплата** = комиссия + бонусы.

## Render
`render.yaml` — Blueprint: web-сервис + Postgres (Frankfurt).

Переменные окружения:
- `BITRIX_WEBHOOK` — входящий вебхук Bitrix24 (права `crm`, `user`, `department`)
- `DASH_PASSWORD` — пароль владельца кабинета
- `ANTHROPIC_API_KEY` — ключ Claude API для AI-ассистента
- `SUPABASE_DB_URL` — основная база (Supabase, строка «Session pooler»). При первом запуске всё из старой базы `DATABASE_URL` копируется сюда автоматически.
- `DATABASE_URL` — старая база Postgres (Render) (в Blueprint подставляется автоматически). Без неё настройки хранятся в файле и пропадают при перезапуске.

Вебхук не попадает в браузер: сервер сам опрашивает Bitrix24 (по умолчанию раз в 30 с), табло опрашивает сервер раз в 5 с.

## Локально
```
npm install
BITRIX_WEBHOOK=... DASH_PASSWORD=123 node server.js   # http://localhost:3000/admin
```

## База, аналитика и AI (v3)

**База Safa** — копия CRM из Bitrix24: сделки (все воронки и стадии), лиды, звонки. Первая загрузка — история за `whDays` дней (по умолчанию 120), дальше каждые 2 минуты только изменения. Хранится в Postgres (таблица `wh_rows`), без Postgres — только в памяти.

**Аккаунты и роли**
- Владелец — входит только по паролю `DASH_PASSWORD`, видит и настраивает всё.
- Руководитель сектора — свой логин/пароль (раздел «Пользователи»), видит только свои секторы: главная, продажи, выплаты, воронка, звонки, AI. Настройки, лидерборд, штрафы и менеджеры ему недоступны (проверяется на сервере).

**Аналитика**
- Воронка и выкуп: лиды → сделки → заказы → выкуплено/отказ/в работе, конверсия лидов, % выкупа по секторам и менеджерам, зависшие заказы по стадиям.
- Звонки: всего, исходящие и дозвон, входящие и пропущенные, минуты, звонков на заказ, скорость первого звонка по новому лиду, лиды без звонка, звонки по часам. Нужен доступ вебхука к телефонии (право `telephony`).

**AI-ассистент** — Claude отвечает на вопросы на казахском и русском по данным базы через инструменты (табло, продажи, воронка, звонки, сделки, источники, зарплата). Ограничения роли применяются на сервере. Нужна переменная `ANTHROPIC_API_KEY` (необязательно: `ANTHROPIC_MODEL`, по умолчанию `claude-sonnet-5-5`).

Права входящего вебхука Bitrix24: `crm`, `user`, `department`, `telephony`.

## Посещаемость (Hikvision)
Кабинет → «Посещаемость» → «Терминал и правила».
- **Способ 1:** в веб-интерфейсе терминала включить *HTTP Listening* на адрес `https://<сайт>/api/att/<ключ>` (HTTPS, 443).
- **Способ 2:** если терминал не умеет HTTPS — запустить в офисе мост: `HIK_HOST=192.168.1.64 HIK_USER=admin HIK_PASS=… node hik-bridge.js` (файл скачивается из кабинета, ключ уже вписан).
- Сопоставить номера сотрудников терминала с менеджерами Bitrix24, задать начало дня, допуск и крайнее время опоздания.
